How it works

1. Open — the agent deposits USDC into a tab for one provider (open), optionally tagging the provider's ERC-8004 agent id.
2. Call — the API answers 402; the agent signs an EIP-712 Voucher(tabId, cumulative) and retries. Zero gas, sub-ms verification.
3. Settle — the provider redeems the latest voucher on Arc in one tx for many calls (redeem / closeByProvider).
4. Exit — the payer can always leave: requestClose → close delay → finalize refunds the unspent balance.
